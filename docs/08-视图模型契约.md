# 08 · 视图模型契约

> 外壳未定，但"一行显示什么、常驻条选哪几条、顶部状态怎么写"不该有两个答案。
> 本文件 + `packages/viewmodel/` 是**跨语言的展示口径**：WPF / Tauri / CLI 都应产出同一份 JSON。

## 1. 输入输出

```js
import { buildViewModel } from "./packages/viewmodel/view-model.mjs";

const vm = buildViewModel({

  isSample: false,   // 加载的是示例快照时 true（影响文案前缀）
  dockItems: 3,      // 常驻条 1–6
```

## 2. 必须一致的展示规则

### 2.1 可见性

`snapshot.games[].hidden` 由生成快照时按三态算好（`hidden` / `defaultHidden` / `shown`），
**视图模型只过滤 `hidden === true`**，不再自行推导。

### 2.2 时间与倒计时

- 输入是源站墙钟文本 `MM-dd HH:mm ~ MM-dd HH:mm`（无年份）；
- 解析时同时试 **去年 / 今年 / 明年**，取离 `now` 最近的窗口（跨年场景）；
- 展示：
  - `now < start` → `还有 X天X小时X分钟 开始`
  - `start ≤ now ≤ end` → `还剩 X天X小时X分钟`
  - `now > end` → `已结束`
  - 解析失败 → 原样显示源文本；
- 解析失败**不报错**，宁可能力降级也不让整行消失。

### 2.3 卡池 / 活动外显

- 卡池：有 `roles` 时外显精简角色名，否则 `banner`，都没有 `—`；
- 活动：`event`，没有 `—`；
- 角色名精简：
  - 去掉 `「」【】`；
  - BA 三服保留 `（泳装）` 这类换装标识（统一成半角括号）；
  - 其它游戏去掉 `（属性/职业）` 后缀；
  - `称号·名字` 取 `·` 后面的名字（4 字以内 `•` 同理）。
- 悬停 `tip` 始终给完整信息（池名 + 角色 + 源站原文时间），即使外显被精简。

### 2.4 失败三态

| 状态 | badge | 文案 |
|---|---|---|
| 正常 | `null` | — |
| `nomatch` | `{kind:"warn", text:"新卡池未公布" / "新活动未公布"}` | 算成功 |
| `down` | `{kind:"err", text:"卡池失败：<reason>"}` | 卡池优先于活动 |
| stale（无 fail 但有旧值） | `{kind:"stale", text:"沿用旧数据"}` | — |

悬停里若该列沿用旧值，另起一行加 `（失败原因）`。

### 2.5 顶部状态

- `statusText = 前缀 · 成功 ok/total`；
  - 前缀：示例快照 `示例数据`；有成功 `联网数据`；否则 `尚未联网`；
  - `ok` 口径：该条目**两侧都不是 down**（`nomatch` 仍算成功），`skipped` 不计；
- `statusTip`：按 卡池失败 / 活动失败 / 新卡池未公布 / 新活动未公布 分组列名字（最多 8 个 + `等 N 个`）；
- `updatedText`：`result.refreshedAt`（无则 `generatedAt`）格式化 `MM-dd HH:mm`；
  示例快照加 `示例快照 · ` 前缀。

### 2.6 常驻条

- 候选 = 当前进行中的卡池/活动；
- 每款游戏最多一条，取**最早结束**的那一侧；
- 按结束时间升序，取 `dockItems`（1–6）条；
- `remaining` 是短倒计时：`X天` / `X时` / `X分`；
- `name` 超过 9 字符时截断为 8 字符 + `…`（`fullName` 保留全名）；
- 没有候选 → `chips: []`，外壳显示 `emptyText`。

## 3. 与 C# 实现的关系

当前 WPF 的展示逻辑在：

- `src/GachaCalendar/ViewModels/RowBuilder.cs`（行文案/倒计时/三态）
- `src/GachaCalendar/ViewModels/MainViewModel.cs`（状态汇总/常驻条）

JS 版本 `packages/viewmodel/view-model.mjs` 按同一口径实现，并有 6 项测试。
**两个实现必须保持一致**，直到外壳选型确定：

- 若最终选 Tauri：前端直接用 JS 版本；
- 若最终选 WPF：可以把 C# 版本作为唯一实现，但新增规则时两边都改；
  或把 JS 版本通过 WebView2 注入（不推荐，增加运行时开销）。

> 后续可以加一个"用同一份 fixture 分别跑 C# / JS"的 parity 测试；
> 当前先以 JS 测试 + 文档口径锁住行为。

## 4. 调试命令

```powershell
# 把 snapshot 渲染成 view-model JSON（不启动 UI）
node packages/viewmodel/cli.mjs --snapshot data/sample-snapshot.json --dock-items 3
```

## 5. 不在此契约内

- 主题色、字体、圆角、动画；
- 图标下载/缓存；
- 窗口尺寸、任务栏停靠、DPI；
- 设置页交互（由 `packages/engine` 的 config/entries 负责）。
